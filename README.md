# BITE&MORE

## Giới thiệu

BITE&MORE là website bán và đặt món ăn trực tuyến, hỗ trợ khách hàng xem sản phẩm, quản lý giỏ hàng, đặt hàng và theo dõi đơn hàng.

## Công nghệ

* Java Servlet / JSP
* HTML / CSS / JavaScript
* SQL Server
* JDBC
* Apache Tomcat
* Maven

## Cấu trúc dự án

```text
src/        # Mã nguồn Java, JSP, HTML, CSS, JavaScript
database/   # Script SQL
docs/       # Tài liệu dự án, UML, Test Case
README.md   # Giới thiệu và hướng dẫn dự án
```

## Hướng dẫn chạy

1. Tạo database và chạy script SQL trong `database/`.
2. Cấu hình thông tin kết nối database.
3. Chạy project trên Apache Tomcat.
4. Truy cập website thông qua `localhost`.
